# UniMatch 🎓

Plataforma gratuita de orientação vocacional para estudantes de escolas públicas,
desenvolvida como projeto de extensão do IME-USP.

## O que é

Quiz de compatibilidade que recomenda cursos universitários com base no perfil do
aluno, usando dados reais do SISU 2024, CAGED 2023 e CBO/MTE.

## Motivação

Estudantes de escolas públicas frequentemente chegam ao ENEM sem informação
suficiente sobre qual curso escolher. O UniMatch busca preencher essa lacuna
de forma gratuita, acessível e baseada em dados.

## Funcionalidades atuais

- Quiz de 10 perguntas com sistema de compatibilidade multidimensional
- 90 cursos mapeados com dados de salário, empregabilidade e nota de corte
- Ajuste de notas de corte por região
- Favoritos e compartilhamento de resultados
